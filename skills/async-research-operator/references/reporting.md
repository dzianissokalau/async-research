# Reporting

Reports should be concise, evidence-backed, and tied to framework state.

## Startup Or Status Report

Include:

- framework CLI path and version, if detected
- workspace path
- autonomy level
- commands run
- health/readiness/workflow summary
- next safe action
- blockers or approvals needed

## Human Decision Request

State the decision needed, evidence files or command outputs, safe options,
consequences, and the recommended default only when the framework state supports
one.

## Progress Or Completion Report

Include changed files, task ID when applicable, validation commands, review or
acceptance status, and residual risks. Distinguish task acceptance from
deliverable readiness.
