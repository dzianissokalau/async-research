# Climate Coffee Economics Example Workspace

This is a minimal `research_ops/` skeleton for the climate/coffee economics
domain pack. It is fixture-only and should be copied to a temporary directory
before experimenting with write-capable commands.

The workspace demonstrates where the domain pack expects:

- clarified briefs under `briefs/`;
- benchmark tasks under `tasks/`;
- source snapshots under `sources/`;
- eval runs under `evals/runs/` when generated or copied from the pack.

Default fixtures are offline. They do not grant permission to browse live
sources, call paid APIs, use credentials, publish private buyer evidence, or
claim broad superiority over Deep Research-style products.
