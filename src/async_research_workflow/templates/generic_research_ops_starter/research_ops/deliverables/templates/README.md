# Deliverable Templates

Use these templates when a task output is being assembled into a durable
deliverable. They keep task acceptance separate from deliverable maturity.

- `deliverable_manifest_template.json` shows the manifest contract.
- `manuscript_readiness_checklist.md` tracks machine-checkable editorial gates.
- `critic_review_prompt.md` gives an independent critic the required rubric.
- `review_response_matrix.md` tracks every material critique to closure.
- `internal_draft_assembly_task.md` assembles accepted source outputs without
  implying external readiness.
- `shareable_memo_polish_task.md` prepares a known-audience memo.
- `working_paper_revision_task.md` handles working-paper revisions after critic
  review.
- `submission_ready_manuscript_cleanup_task.md` handles venue-targeted final
  cleanup only after manuscript gates and response rows are closed.

The same templates are also packaged under
`async_research_workflow/templates/artifact_templates/` for reference outside
starter workspaces.

Run `async-research deliverable check research_ops <DELIVERABLE-ID>` before any
external-readiness claim.
